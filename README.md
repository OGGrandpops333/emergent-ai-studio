# emergent-ai-studio

An AI studio application built with React Native and Expo.

## Overview

emergent-ai-studio lets you browse, search, and manage your archived and completed AI projects from one place.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or newer)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)

### Install dependencies

```bash
npm install
```

### Run the app

```bash
# Start the Expo dev server (opens a QR code for iOS/Android)
npm start

# Run on Android
npm run android

# Run on iOS
npm run ios

# Run in the browser
npm run web
```

## Find Old Projects Feature

The **Old Projects** screen lets you:

- **Search** across project names, descriptions, and tags in real time.
- **Filter** the list by status — All, Archived, or Completed.
- **View details** for any project by tapping its card.
- **Pull-to-refresh** to sync the latest changes from local storage.

Sample AI projects are seeded automatically on first launch so the screen is never empty.
