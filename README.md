# Emergent AI Studio

An AI studio application built with React Native and Expo. Your all-in-one platform for AI-powered creativity and productivity.

## What can it do?

| Feature | Description |
|---|---|
| 💬 AI Chat | Have natural conversations with a powerful AI assistant |
| 🎨 Image Generation | Create stunning images from text descriptions |
| 📝 Text Summarization | Quickly summarize long documents and articles |
| 🔍 Smart Search | Search your content with semantic understanding |
| 🌐 Translation | Translate text between dozens of languages instantly |
| 🧠 Knowledge Base | Build and query a personal AI-powered knowledge base |
| 📊 Data Analysis | Extract insights from structured data |
| ⚡ Automation | Automate repetitive tasks with AI |

## Screens

- **Studio (Home)** — Overview of features with a quick-start button to the AI Chat.
- **Chat** — A conversational AI interface where you can message the assistant (type `help` to see capabilities).
- **Features** — Full catalogue of everything Emergent AI Studio can do.

## Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npm start

# Run on Android
npm run android

# Run on iOS (requires macOS)
npm run ios

# Run on web
npm run web
```

## Tech Stack

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/) ~54
- [React Navigation](https://reactnavigation.org/) v7 (bottom tabs + native stack)
